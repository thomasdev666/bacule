Bascule

Aide Basile à garder sa planche en équilibre : fais tomber des poids, fusionne les poids identiques, envole le 128 et bats ton record.

Aide

  • Jouer : glisse le doigt pour viser, relâche pour poser le poids. Deux poids identiques qui se touchent fusionnent.
  • Défi du jour : la même suite de poids pour tout le monde, chaque jour.
  • Duel en direct : Accueil → Duel → « Défier un ami » crée un code. Envoie l'invitation (ou le code) à ton ami : il touche le lien, ou ouvre Bascule → Duel → « Rejoindre un duel ». Vous jouez la même partie, avec les mêmes poids et les mêmes rafales, et tu vois sa planche en direct. Le premier qui lâche a perdu. Il faut internet et deux téléphones.
  • Code ami : dans Classement → Amis, partage ton code pour comparer vos scores.
  • Achats : pour retrouver un achat (sans publicité, pack Légendes…), touche « Restaurer mes achats » dans les réglages ou la boutique.

Règles du classement

Les pseudos sont visibles par tous les joueurs. Interdit : insultes, propos choquants ou haineux, informations personnelles (nom, adresse, numéro, réseau social). Chaque joueur peut signaler un pseudo ou bloquer un joueur depuis le classement (bouton « Signaler »). Les signalements sont traités sous 24 h : un pseudo qui ne respecte pas ces règles est supprimé, et le joueur peut être retiré du classement.

Contact

Une question, un bug, une demande sur tes données : écris-nous à contact@orpheex.fr (réponse sous 24 h). Indique ton code ami (Classement → Amis) pour qu'on retrouve ton compte de jeu.
