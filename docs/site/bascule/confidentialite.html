Ce que le jeu collecte

  • Un identifiant de joueur anonyme, créé automatiquement au premier lancement pour le classement en ligne. Il n'est relié ni à votre nom, ni à votre e-mail, ni à votre numéro de téléphone.
  • Le pseudo que vous choisissez (facultatif), vos scores et la tête portée. Ils sont visibles par les autres joueurs dans les classements.
  • Les codes amis que vous ajoutez, pour afficher le classement entre amis.
  • Votre progression (niveau, pièces, têtes, réglages) : elle est enregistrée sur votre téléphone uniquement.
  • Des statistiques de jeu anonymes (parties jouées, durée, scores) enregistrées sur votre téléphone pour améliorer le jeu. [Si un service d'analyse est ajouté plus tard, le nommer ici.]

Le jeu ne collecte ni votre position, ni vos contacts, ni vos photos, ni votre micro.

Publicités

Le jeu est gratuit et affiche des publicités fournies par Unity Ads (Unity Technologies). Elles sont non personnalisées : le jeu demande à la régie de ne pas utiliser vos données pour vous cibler. Unity Ads peut traiter des données techniques (modèle d'appareil, adresse IP, langue) pour afficher et compter les publicités : voir la politique de confidentialité de Unity.

Achats

Les achats (sans publicité, pièces, têtes) sont payés via l'App Store ou Google Play. Orphex ne reçoit jamais vos coordonnées bancaires.

Notifications

Si vous les acceptez, le jeu programme au plus un rappel par jour sur votre téléphone (cadeau du jour, série). Aucune donnée n'est envoyée pour cela. Vous pouvez les couper dans les réglages du jeu ou du téléphone.

Qui traite les données en ligne ?

Le classement en ligne utilise Unity Gaming Services (Unity Technologies), qui héberge l'identifiant anonyme, le pseudo et les scores. Ces données peuvent être traitées hors de l'Union européenne, avec les garanties prévues par le RGPD (clauses contractuelles types).

Combien de temps ?

Les données du classement sont conservées tant que le compte de jeu existe, et au plus [durée, par exemple 2 ans] après la dernière partie. Les données sur le téléphone disparaissent quand vous désinstallez le jeu.

Vos droits

Vous pouvez accéder à vos données, les corriger ou les supprimer. Dans le jeu : Réglages → « Supprimer mes données en ligne » efface votre compte de jeu, votre pseudo et vos scores en ligne. Vous pouvez aussi nous écrire (en indiquant votre code ami) et saisir la CNIL (cnil.fr).

Âge

Bascule s'adresse aux joueurs de 13 ans et plus.
